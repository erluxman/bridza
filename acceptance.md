# Inbox Zero Confetti — Acceptance

## Confetti trigger

- [ ] Open inbox when it has items → no confetti plays
- [ ] Open inbox when empty (0 tasks) → confetti animation plays

## Confetti behavior

- [ ] Confetti animation is visible and celebratory (2-3 seconds)
- [ ] Confetti fires only once per session when opening empty inbox
- [ ] Refreshing the page resets the confetti trigger (can play again)

- [ ] `pnpm test` passes
- [ ] `pnpm lint` passes
