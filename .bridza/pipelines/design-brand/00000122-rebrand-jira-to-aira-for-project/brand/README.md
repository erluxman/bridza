| What | Path |
|---|---|
| Original brand board (1536×1024) | `reference/aira-brand-board.png` |

## Palette

| Name | Hex | Role |
|---|---|---|
| Primary Blue | `#4F7BFF` | accent, links, buttons, focus |
| Purple | `#8B5CF6` | gradient end, AI highlights |
| Cyan | `#06D6A0` | success, "AI ready" |
| Dark Navy | `#0B1120` | dark base, wordmark on light |
| Slate | `#64748B` | secondary text, borders |
| Light | `#F8FAFC` | light surface, wordmark on dark |

Gradient: `linear-gradient(90deg, #4F7BFF, #8B5CF6)`.
